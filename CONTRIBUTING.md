# Contributing

Thanks for helping make Untab useful and small.

For a bug, open an issue with your OS, Untab version and steps to reproduce. Don't include your library, private links or files. For a substantial feature, start with an issue so we can agree on the scope.

1. Follow the [development guide](docs/development.md)
2. Keep the change focused and add a regression test when it protects meaningful behavior
3. Run the checks relevant to your change and describe the result in your pull request

Use Conventional Commits, such as `fix: preserve attachments during import` or `feat: add a file filter`. Maintainer commits and release tags are PGP-signed. Keep code comments concise and without a trailing period. Be respectful when discussing changes.
